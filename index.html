🔬 Exploratory Data Analysis

Before any model is trained, we analyse the raw dataset — class balance, image dimensions, pixel-intensity statistics, and a data-quality audit — to confirm the pipeline is clean and the feature space is informative.

💡

Key observation: The dataset is near-balanced across all four classes, validating accuracy as a fair metric. Meningioma and No-Tumor share overlapping intensity distributions, which explains why they are the hardest pair to separate downstream.

🌲 Baseline ML — Random Forest

A Random Forest (200 trees, class-balanced) trained on ~370 hand-crafted features: HOG edge descriptors, LBP texture patterns, GLCM co-occurrence stats, and raw intensity statistics. Uncertainty is estimated via Shannon entropy over tree-vote distributions.

🧠 Random Forest · 200 trees · balanced weights · ~370-dim feature vector · uncertainty via Shannon entropy

⚡ Advanced ML — SVM + PCA + Platt Scaling

SVM with RBF kernel (C=10) applied in PCA-compressed space retaining 95% variance. Platt Scaling converts raw SVM scores into calibrated probabilities. The maximum-margin boundary in PCA space resolves the non-linear Glioma ↔ Meningioma boundary that Random Forest struggles with.

⚡ SVM · RBF kernel · C=10 · PCA 95% variance · Platt calibration · uncertainty via calibrated entropy

🧠 Deep Learning — ResNet-18 + MC-Dropout

ResNet-18 with pretrained ImageNet weights, fine-tuned on brain MRI. MC-Dropout (20 passes) provides uncertainty estimation via Shannon entropy of prediction distributions. Temperature scaling ensures calibrated probabilities for clinical safety.
